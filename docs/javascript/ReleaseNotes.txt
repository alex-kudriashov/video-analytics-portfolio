JS VIDEO ANALYTICS VIEWER — ИСТОРИЯ ИЗМЕНЕНИЙ
=============================================

Текущая версия: 1.0.13

2026-10-06 — раздельные идентификаторы истории сопровождения
-------------------------------------------------------------
* В таблице «История сопровождения» Motion ID и идентификатор распознавания
  Tracking-YOLO-256 вынесены в отдельные колонки.
* Motion ID всегда отображается как `track-N`, включая числовой формат Python;
  у нераспознанной записи в колонке YOLO выводится «—».
* Устранено неоднозначное представление `YOLO N · track-M` в общей колонке
  «Идентификатор»; таблица пустой истории теперь использует девять колонок.

2026-10-02 — ручной выбор частоты HLS
--------------------------------------
* Рядом с разрешением HLS добавлен независимый список 15/30 FPS.
* Текущее значение читается из конфигурации Server. Переключение HLS, загрузка
  страницы и смена разрешения отправляют только `height` и больше не могут
  автоматически изменить частоту; `fps` передаётся только после явного выбора.
* Управление FPS, как и разрешением общего HLS-потока, доступно только роли
  `admin`; для `viewer` оба списка заблокированы.

2026-09-04 — фиксированный upstream и защищённый HLS
=====================================================
* Удалено управление адресом прокси через клиентский `x-server-url`; Viewer
  принимает только пути `/api/v1/*` и использует заданный окружением upstream.
* HLS перенесён на единый путь `/hls/`, допускает только плейлист и сегменты и
  перед выдачей проверяет Bearer-сессию через VideoAnalyticsServer.
* Адрес Server в интерфейсе сделан только для чтения; из публичного HTML убраны
  начальные домашний IP камеры и имя пользователя.
* Добавлены тайм-ауты прокси и автоматическая проверка подмены upstream,
  запрещённого пути и HLS с авторизацией и без неё.
* `npm run check`, `npm test` и Docker Release-сборка выполнены успешно. Новый
  контейнер запущен на `127.0.0.1:15173`; runtime-проверки SSRF, путей прокси и
  анонимного HLS дали ожидаемые ответы 200, 404 и 401.

JPEG и HLS
----------
* JPEG переведён с Blob URL на один canvas с явным ImageBitmap.close().
* JPEG-режим ограничен частотой 15 кадров/с.
* HLS больше не использует серверный iframe.
* Qt- и Python-сервер подключаются через единый video/hls.js и локальный прокси.
* SourceBuffer очищается, а MediaSource, hls.js и video пересоздаются раз в десять
  минут для ограничения памяти Chromium.
* HLS сохраняет пропорции, центрируется и вписывается в окно как JPEG.
* Рядом с Server FPS добавлен реальный Viewer FPS.
* Журнал вкладки ограничен 200 записями.
