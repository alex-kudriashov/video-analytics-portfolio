2026-08-25 — Tracking YOLO 256 в истории сопровождения
------------------------------------------------------
* Добавлен отдельный постоянный поток `tracking-onnx-object-detector` со своей
  ONNX Runtime session; полнокадровый YOLO 2304 продолжает работать независимо
  в потоке `onnx-object-detector`.
* Для каждого свежего подтверждённого Motion ID формируется нативный
  центрированный кроп 256×256: малая Motion-рамка задаёт только центр, поэтому
  автомобиль или человек попадает во вход целиком. Фон вне соответствующей
  области сопровождения маскируется серым.
* Жёлтая и синяя фотографии строятся из той же ROI, которая была передана
  Tracking YOLO; вход и снимок поэтому показывают один объект.
* В payload Tracking сохранены исходные `x`, `y`, `width`, `height`.
* `trackingCropPadding` сохранён в REST для совместимости, но не ограничивает
  нативный вход Tracking YOLO, как и в текущей реализации Clang.
* Строка Tracking и жёлтое фото создаются сразу после подтверждения трека;
  `photoDelaySeconds` оставлен только для совместимости REST.
* Лучший результат YOLO обновляет ту же строку, заменяет фото синим и добавляет
  канонический `yoloId`, не выполняя повторный INSERT.
* Несколько Motion ID одной YOLO-рамки объединяются в одно событие PostgreSQL;
  история остаётся открытой до удаления трека после `maximumMisses`.
* Добавлены проверки отдельного имени worker-потока, фактического входа
  256×256, немедленного снимка, временного пропуска, синего обновления и
  объединения Motion ID. Полный набор из 38 тестов завершился успешно.
* Динамическая runtime-модель отдельно загружена новым worker и успешно
  выполнила реальный inference 256×256 без ошибки формы ONNX-тензора.
* Запущенный экземпляр Server не перезапускался.

* Motion вынесен в отдельный асинхронный worker.
* Motion и YOLO используют busy/skip без копирования кадров в растущую очередь.
* Разбор результатов YOLO векторизован через NumPy.
* OpenCV ограничен двумя потоками; ONNX использует два intra-op и один
  inter-op поток.
* Добавлены подробные комментарии о потоках и тесты многопоточной логики.
