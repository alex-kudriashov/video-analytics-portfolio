# Безопасность и границы публикации

## Аутентификация и роли

REST API использует Bearer-сессии. Пароли пользователей хранятся в виде PBKDF2-SHA256 производных. Роли admin и viewer разделяют операции изменения конфигурации и чтения данных.

## Защита данных камер

Реквизиты RTSP и ONVIF не включаются в ответы API, журналы и диагностические метрики. Клиент видит только сведения, необходимые для выбора и управления камерой.

## Проверка входных данных

Маршруты проверяют типы и допустимые диапазоны параметров. Имена файлов принимаются только из каталога записей. Фильтры истории передаются в PostgreSQL параметризованными запросами, а поля сортировки выбираются из закрытого списка.

## Состав публичного репозитория

Этот репозиторий содержит только обзорную документацию самостоятельного проекта. В публикацию не входят:

- исходный код;
- модели и наборы данных;
- конфигурационные файлы;
- адреса камер и сетевой инфраструктуры;
- логины, пароли, токены и сертификаты;
- журналы работы и записи видео;
- материалы прежних работодателей и заказчиков.
