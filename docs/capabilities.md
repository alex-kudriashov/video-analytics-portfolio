# Функциональные возможности

## Источники видео

Система принимает RTSP-поток от IP-камеры или локальный видеофайл. Для камеры реализованы повторные подключения, контроль невалидных кадров и метрики успешных и неуспешных попыток. Видео из файла проходит через тот же аналитический конвейер и воспроизводится с записанной частотой кадров.

## Детекция движения и Tracking

Детектор движения работает в настраиваемых областях. Трекер сопоставляет цели между кадрами, присваивает постоянные идентификаторы и строит траектории. Параметры подтверждения и допустимого числа пропусков позволяют отфильтровывать кратковременный шум.

## YOLO и ONNX Runtime

Нейросетевой детектор загружает модели YOLO в формате ONNX. Реализованы подготовка изображения, масштабирование с сохранением пропорций, формирование тензора, запуск inference, Non-Maximum Suppression и перевод координат обратно в исходный кадр.

Используются два независимых режима:

- анализ полного кадра или выбранных прямоугольных областей;
- анализ изображений сопровождаемых целей для уточнения их класса.

## Области анализа

YOLO и Tracking используют отдельные наборы областей. Для каждой области можно выбрать разрешение inference. Это позволяет направлять вычислительные ресурсы на важные зоны и не анализировать остальную часть кадра.

## Просмотр и запись

Сервер публикует JPEG preview и HLS-поток. Разработанный на JavaScript браузерный клиент показывает текущее видео, рамки, траектории, параметры потока и историю событий.

Запись получает исходные кадры из уже открытого RTSP-сеанса и не создаёт второе подключение к камере. Видеофайл кодируется в H.264 и корректно завершается в MP4 после команды остановки.

## Публичный доступ

Работа демонстрационного решения доступна через публичный VPS [alex-video-analytics.ru](https://alex-video-analytics.ru/). Он предоставляет единую HTTPS-точку входа для JavaScript-клиента, REST API и HLS, не раскрывая внутренние адреса компонентов.

## Управление камерой

Администратор может добавлять и изменять камеры, выбирать активный источник и отправлять ONVIF PTZ-команды. REST-ответы не содержат пароли камер.

## REST API

API предоставляет операции для:

- проверки состояния сервера и видеопотока;
- настройки Motion, Tracking и YOLO;
- управления областями анализа;
- чтения и очистки истории;
- управления камерами и PTZ;
- запуска и остановки записи;
- получения диагностического журнала и метрик профилирования.
